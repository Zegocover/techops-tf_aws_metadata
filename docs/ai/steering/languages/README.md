# Languages Standards

- [python.md](python.md) — structural and architectural conventions for Python: functional core/imperative shell, composition root, type annotations, Pydantic vs dataclass, protocols, async I/O, docstring style, and testing tooling (pytest, pytest-asyncio, coverage enforcement).
- [hcl.md](hcl.md) — structural and operational conventions for HCL/Terraform: canonical file layout, typed variables and described outputs, `validation {}` blocks, workspace + env tfvars pattern, exact `required_version` and pessimistic provider pinning, committed lockfiles, S3 backend with DynamoDB locking, secrets via Secrets Manager and `secrets-config`, `default_tags` on the AWS provider, Buildkite-enforced `terraform fmt`/`tflint`/`validate`, Buildkite plan-as-artefact pattern, and module extraction with `terraform-docs` and strict semver tags.
- [scala.md](scala.md) — structural and architectural conventions for Scala 2.13: functional core/imperative shell, composition-root DI, sealed-trait ADTs, smart constructors, `cats-core` scope, `Future` + Akka concurrency, gRPC and AWS-adapter boundaries, and testing tooling (ScalaTest, ScalaCheck, Testcontainers/LocalStack, scoverage).
- [swift.md](swift.md) — stack-agnostic Swift conventions: force-unwrap/cast prohibition, explicit empty-collection types, async/await, @MainActor on @Published-owning types, weak self in escaping closures, no magic values, doc comments, XCTest AAA, mock-at-the-DI-boundary, real fixtures, snapshot tests, format-before-lint.
- [kotlin.md](kotlin.md) — stack-agnostic Kotlin conventions: cancellation-safe coroutine error handling, injected I/O dispatcher, cold Flows, `sealed interface` over `sealed class`, `data object` variants, extension-function mappers, nullable-return-type contract, `runTest` + `advanceUntilIdle`, injected test dispatcher.
